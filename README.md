# 博物馆单张展签排版工具

一个自托管的 **单张博物馆展签（object label）排版 / 打印** Web 工具：
输入标题、中英混排说明文字和展签物理宽高（毫米），浏览器实时预览并可直接按真实尺寸打印或导出 PDF。

- 后端：Node.js + Express（仅托管静态页面与健康检查，无数据库）
- 前端：原生 HTML / CSS / JavaScript，零前端构建、零外部 CDN
- 排版核心：Canvas 实测字宽 + 动态规划断行，浏览器与打印共用同一份换行结果
- 依赖随容器启动自动安装，**不需要任何第三方账号 / 联网服务**

---

## 一条命令启动

需要安装 Docker（含 Compose 插件）。

```bash
docker compose up --build
```

启动后浏览器打开：

> **http://localhost:3000**

停止：在终端按 `Ctrl+C`；后台运行用 `docker compose up --build -d`，查看日志 `docker compose logs -f`。

> 首次启动会自动执行 `npm install`（依赖安装到独立的 Docker 命名卷中，之后重启 / 重建容器会直接复用，无需重复下载）。

### 不用 Docker 时（本机有 Node.js ≥ 18）

```bash
npm install
npm start
# 同样访问 http://localhost:3000
```

## 必要配置

| 配置项 | 位置 | 默认值 | 说明 |

```bash
PORT=8080 docker compose up --build      # http://localhost:8080
```

或直接编辑 `docker-compose.yml` 中的 `ports`（如 `"8080:3000"`）。

## 使用说明

1. 在左侧输入 **标题** 与 **说明正文**，设定展签 **宽 / 高（毫米）**。
2. 右侧实时等比预览；状态栏显示当前采用的正文字号、标题字号、行数与实际占用高度。
3. 点击 **打印 / 导出 PDF**：浏览器打印对话框中纸张会自动设为展签的毫米尺寸，
   边距选“无”、缩放选“100% / 默认”即可得到与预览逐行一致的实物；选择“另存为 PDF”可导出矢量 PDF。
4. **载入示例** 可快速查看一条典型陶瓷器展签的排版效果。正文以空行分段。

### 装不下时

工具不会截断或溢出遮挡文字。即使最小字号 12px 仍放不下时，预览区会明确报错并区分原因：

- **超宽**：存在比整行还宽的不可拆英文单词 / 连字 → 提示加宽展签或缩短该词；
- **超高**：12px 下总高度仍超出展签 → 提示加高展签或精简文字（同时给出内容高度与可用高度，单位 mm）。

## 排版规则（实现细节）

### 1. 分词

正文先按 Unicode 切分为不可拆 / 可断点的片段（`public/layout.js`）：

- **英文 / 数字单词整体不可拆**，词内允许常见连接符：`New-York`、`1.5`、`don't`、`A/B`；
- 汉字（含扩展区、假名、韩文音节、全角字符）以**单字为原子**，字间均可断行；
- 破折号连用（`——`）、省略号（`……`）、叠用叹问号（`！！`、`？？`）作为不可拆整体；
- 连续空白折叠为一个断点，行首尾不挂空格。

### 2. 避头尾（禁则）

- **闭标点不居行首**：`）、】、》、」、』、”、’、，、。、：、；、！、？、…、—` 及对应半角；
- **开标点不居行尾**：`（、【、《、「、『、“、‘` 及 `( [ {`。

### 3. 目标函数：最小化非末行空白平方和

在满足上述硬约束的所有排法中，定义某一非末行的剩余空白为
`空白 = 行可用宽 − 该行实际文字宽`（不计行尾悬挂空格），求解

```
minimize   Σ (各非末行空白)²
```

**末行不参与惩罚**（允许自然留白）。该问题用动态规划求解（类 TeX 行断点算法），
时间复杂度 O(n²)，对展签这种短文本瞬间完成；平方代价会优先把“差一点填满”的行收紧，
避免某一行出现突兀的大空洞。

### 4. 字号选择

- 正文字号从 **24px 到 12px 逐档**（整数 px）尝试，取能同时放入宽与高的**最大者**；
- 标题字号 = 正文字号 × 1.5（加粗），标题与正文参与同一高度预算；
- 行距：正文 1.6 倍、标题 1.35 倍；标题—正文间距 2.5 mm，段落间距 0.7 em；
- 四周内边距 6 mm；任何一档都放不下则报错（不缩放、不截断）。

### 5. 字宽从哪里来、为何打印与预览一致

所有字宽由浏览器 **Canvas 2D `measureText`** 在“当前字号 + 实际字体栈”下逐个测得，
排版结果再以相同的字号 / 行距 / 毫米尺寸渲染成 DOM。预览与打印版是同一份 DOM 结构：
打印 CSS（`@page { size: <宽>mm <高>mm; margin: 0 }`）隐藏操作界面、只输出展签，
因此**预览的每一行就是打印的每一行**。

> 字号与物理毫米的换算遵循 CSS 参考像素标准：`1px = 25.4/96 mm`（96 DPI）。
> 实际打印精度取决于浏览器与打印机驱动；不同系统自带中文字体的字面宽度略有差异，
> 对尺寸要求极高时建议在打印用机器上安装统一字体（如思源黑体 / 宋体）。

## 常见问题

**打印出来尺寸不对？**
打印对话框中关闭页眉页脚、边距选“无”、缩放必须为“100% / 默认（不要适合页面）”。
Chrome / Edge 对毫米尺寸的 `@page size` 支持最好；若个别浏览器忽略该设置，
在系统打印对话框手动新建同尺寸纸张即可。

**需要联网或 API Key 吗？**
不需要。除 `npm install` 从 npm 源拉取 Express 外，运行期完全离线可用，无任何第三方账号。

**数据会上传吗？**
不会。文字测量与排版全部在你的浏览器内完成，后端只发送静态文件。
